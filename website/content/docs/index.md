Hokan is a Rust command-line tool that keeps your existing shell and adds contextual completion inside the terminal. These guides cover installation, shell integration, configuration, AI actions, and recovery when a terminal session needs help.

## Find your path

- **New to Hokan?** Start with [installation](/docs/getting-started/install), then try the [first shell session](/docs/getting-started/first-shell).
- **Tuning suggestions?** Read about [completion sources](/docs/concepts/completion-sources) and [configuration](/docs/reference/configuration).
- **Working with AI?** See [explicit AI actions](/docs/guides/ai).
- **Something went wrong?** Use the [troubleshooting guide](/docs/troubleshooting).

Hokan is currently in public beta. The [compatibility matrix](/docs/reference/compatibility) records the tested shell, terminal, SSH, and tmux combinations.
