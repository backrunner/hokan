# Hokan documentation site

This directory contains the public Hokan documentation site, built with svedocs. It is a static SvelteKit app with local search, Markdown twins for agents, sitemap/robots output, structured data, and page-level Open Graph PNGs.

## Local development

```bash
cd website
pnpm install
pnpm dev
```

The default canonical origin is `https://hokan.pwp.sh`. Override `SITE_URL` for other deployments; it must be an HTTP(S) origin without a path:

```bash
SITE_URL=https://hokan.pwp.sh pnpm verify
```

## Checks

```bash
pnpm check:content
pnpm check
pnpm build
pnpm test:site
```

`pnpm test:site` exercises every generated page, metadata, OG image, Markdown twin, search, copy controls, theme mode, mobile navigation, anchors, and the 404 page.

## Deploy to Cloudflare Pages

The production Pages project is `hokan`, with the alias `https://hokan.pages.dev`:

```bash
SITE_URL=https://hokan.pwp.sh pnpm verify
wrangler pages deploy build --project-name hokan --branch main --commit-dirty=true
```

The intended custom domain is `https://hokan.pwp.sh`. In the `pwp.sh` Cloudflare zone, add a proxied CNAME record named `hokan` pointing to `hokan.pages.dev`, then wait for Pages certificate validation to become active.

## Assets

- `static/logo.svg` is the Hokan H-and-cursor mark used for the favicon and navbar.
- `og-template.ts` defines the 1200×630 Open Graph template, using the same typography and paper background as the site.
- `static/og/*.png` is generated by `pnpm og` and ignored by Git; deployment builds regenerate it.
